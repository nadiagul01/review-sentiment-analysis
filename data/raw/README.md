# data/raw/

Put **`Reviews.csv`** in this folder. The dataset is not stored in this repository
because of its size; download it from the original source.

## How to get it

1. Open https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews
2. Sign in (a free Kaggle account works) and click **Download**.
3. Unzip the download and copy `Reviews.csv` into this folder.

## About the dataset

Amazon Fine Food Reviews - 568,454 product reviews written on Amazon between
October 1999 and October 2012, collected by the Stanford Network Analysis Project (SNAP).

Columns: `Id`, `ProductId`, `UserId`, `ProfileName`, `HelpfulnessNumerator`,
`HelpfulnessDenominator`, `Score` (1-5 stars), `Time`, `Summary`, `Text`.

Source: J. McAuley and J. Leskovec, "From amateurs to connoisseurs: modeling the evolution
of user expertise through online reviews", WWW 2013.
